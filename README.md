💌 #Animated Message Template#

Description : A small animated web template for sending a heartfelt message. Built with HTML, CSS, and JS — no dependencies, no backend.

Demo :-

(https://udaygit57.github.io/Animated-Message-Template/)

Usage
1. Clone the repo
2. Open index.html in your browser
3. Replace the placeholder text with your own message, tweak colors/fonts in style.css
